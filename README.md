# PROYEK-MTR
Math Tower Race for KCB's assignment

## Deskripsi
Game balap matematika edukatif interaktif berbasis web dengan mode permainan Human vs Bot (PvE) dan Human vs Human (PvP Realtime).

## Fitur Utama
- **Multiplayer Real-time**: Menggunakan Firebase Realtime Database untuk sinkronisasi antar perangkat (bebas bermain di HP/Laptop berbeda).
- **Independent Player State**: Level, timer, dan progres soal berjalan secara independen untuk masing-masing pemain tanpa saling mengganggu.
- **Dynamic Leveling**: Visual background dan tingkat kesulitan soal otomatis meningkat dari Level 1 hingga Level 5.
